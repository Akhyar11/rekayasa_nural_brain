================================================================================
RANCANGAN ARSITEKTUR: PREDICTIVE SPIKING COGNITIVE MODEL (PSCM)
Untuk Pemrosesan Bahasa Alami Berbasis Biologis (Biologically Plausible Language Model)
================================================================================

Dokumen ini memuat cetak biru arsitektur PSCM, yaitu sebuah alternatif model bahasa
yang dirancang untuk meniru mekanisme biologis otak manusia, meninggalkan paradigma
Transformer konvensional dan algoritma Backpropagation global.

--------------------------------------------------------------------------------
2. SPESIFIKASI DETAIL KOMPONEN ARSITEKTUR
--------------------------------------------------------------------------------

A. TEMPORAL SPIKING TOKENIZER (INPUT LAYER)
   - Fungsi: Mengubah representasi teks statis menjadi representasi temporal dinamis.
   - Mekanisme: Setiap token atau sub-kata dipetakan ke dalam frekuensi tembakan 
     (firing rate) atau latensi waktu tertentu. Kata yang memiliki kedekatan semantis 
     akan memicu sekelompok "neuron input" untuk menyala dalam jendela waktu (window) 
     yang berdekatan.

B. HIERARKI KOLOM KORTIKAL & PREDICTIVE CODING
   - Struktur: Terdiri dari tumpukan lapisan saraf yang terhubung dua arah (Koneksi 
     Amanah/Feedforward dan Koneksi Umpan Balik/Feedback).
   - Mekanisme Prediksi: Lapisan atas menghasilkan prediksi konstan (Top-Down) mengenai 
     representasi kata berikutnya. Lapisan bawah membandingkan prediksi ini dengan 
     input riil dari Tokenizer. 
   - Transmisi Eror: Jika terjadi ketidaksesuaian, sistem hanya meneruskan sinyal eror 
     (Prediction Error) ke lapisan atas untuk memperbarui keadaan internal. Jika tepat, 
     tidak ada sinyal dikirimkan (Zero Compute / Energy Saving).

C. NODE NEUROMODULATOR DINAMIS (PENGGANTI ATTENTION RECHAMISM)
   - Fungsi: Menggantikan fungsi kalkulasi matriks 'Self-Attention' yang berat.
   - Mekanisme: Bertindak seperti Asetilkolin (atensi/fokus) dan Dopamin (sistem reward/
     konformitas makna). Ketika model mendeteksi adanya struktur linguistik yang 
     penting atau kejutan informasi (high prediction error), node neuromodulator akan 
     melepaskan "sinyal kimiawi buatan" ke area lokal. Sinyal ini menurunkan ambang 
     batas tembakan (firing threshold) neuron target, membuat mereka lebih sensitif 
     terhadap input konteks saat itu.

D. SISTEM MEMORI GANDA (DUAL-MEMORY SYSTEM)
   - Modul Hipokampus: Menggunakan algoritma Hebbian lokal murni yang agresif. Memiliki 
     plastisitas tinggi untuk menyimpan informasi baru dalam sekali lihat (one-shot 
     learning). Memori disimpan dalam bentuk koneksi sinapsis ephemeral.
   - Modul Neokorteks: Menyimpan bobot bahasa jangka panjang (tata bahasa, logika, 
     pengetahuan universal). 
   - Proses Konsolidasi (Off-line Learning): Saat model dalam kondisi idle (fase 
     meniru tidur), data dari Hipokampus di-replay berulang kali dengan kecepatan tinggi 
     ke Neokorteks untuk memicu perubahan bobot permanen secara perlahan tanpa merusak 
     pengetahuan lama (Mencegah Catastrophic Forgetting).

--------------------------------------------------------------------------------
3. MEKANISME BELAJAR (ATURAN PEMBARUAN BOBOT LOKAL)
--------------------------------------------------------------------------------

Model ini melarang adanya Backpropagation global. Pembaruan bobot sinapsis (W) 
menggunakan kombinasi dua aturan lokal:

1. STDP (Spike-Timing-Dependent Plasticity):
   - Jika neuron pre-sinaptik (input) menyala beberapa milidetik SEBELUM neuron 
     post-sinaptik (output), maka bobot sinapsis diperkuat (Long-Term Potentiation).
   - Jika neuron pre-sinaptik menyala SETELAH neuron post-sinaptik, bobot dilemahkan 
     (Long-Term Depression).
   - Rumus Delta W berbasis perbedaan waktu delta_t = t_post - t_pre.

2. Pembaruan Berbasis Eror Prediksi Lokal (Forward-Forward Kontrastif):
   - Setiap lapisan mengoptimalkan dirinya sendiri untuk meminimalkan eror lokal 
     sebelum meneruskan representasi ke lapisan berikutnya.

================================================================================
REKOMENDASI BAHASA PEMROGRAMAN DAN LIBRARY
================================================================================

Untuk mengimplementasikan arsitektur ini dari tahap Proof of Concept (PoC) hingga 
skala penuh, berikut adalah rekomendasi bahasa pemrograman beserta argumen teknisnya:

1. PYTHON (Sangat Direkomendasikan untuk Tahap Awal / Prototyping)
   - Alasan: Ekosistem riset kecerdasan buatan terbesar dan memiliki library khusus 
     untuk Spiking Neural Networks (SNN).
   - Library yang Wajib Digunakan:
     * snnTorch: Library berbasis PyTorch untuk merancang SNN dengan gradien buatan 
       (surrogate gradients) sehingga memudahkan eksperimen awal.
     * BindsNET: Library Python yang dirancang khusus untuk membangun SNN di atas 
       PyTorch dengan fokus pada pembelajaran Hebbian dan STDP lokal (sangat cocok 
       dengan PSCM).
     * Brian2: Simulator jaringan saraf biologis yang sangat akurat untuk memodelkan 
       persamaan diferensial neuron (seperti model Leaky Integrate-and-Fire).

2. C++ / CUDA (Direkomendasikan untuk Tahap Produksi & Akselerasi Performa)
   - Alasan: SNN membutuhkan komputasi asinkron berbasis waktu yang sangat intensif. 
     Representasi tingkat rendah di C++ memberikan efisiensi memori yang jauh lebih 
     tinggi dibanding Python.
   - Library yang Wajib Digunakan:
     * GeNN (GPU-enhanced Neural Networks): Memungkinkan komputasi SNN berbasis 
       persamaan biologis langsung di atas kartu grafis NVIDIA menggunakan CUDA dengan 
       kecepatan tinggi.

3. RUST (Alternatif Modern untuk Sistem Asinkron)
   - Alasan: Otak manusia bekerja secara asinkron (setiap neuron berjalan mandiri). 
     Fitur "Fearless Concurrency" milik Rust sangat ideal untuk mensimulasikan ribuan 
     atau jutaan neuron yang menembakkan sinyal secara independen tanpa risiko 
     data race.
   - Library yang Wajib Digunakan:
     * Spike (atau membangun framework custom): Keamanan memori Rust memastikan 
       simulasi skala besar berjalan stabil.

--------------------------------------------------------------------------------
Rekomendasi Langkah Awal Pembuatan:
Buatlah prototipe kecil menggunakan PYTHON dan BINDSNET. Definisikan sebuah kamus kata 
kecil (misal: 100 kata), ubah menjadi spike trains, dan latih satu Cortical Column 
menggunakan aturan STDP untuk melihat apakah model mampu memprediksi urutan 2-3 kata 
sederhana secara mandiri.
